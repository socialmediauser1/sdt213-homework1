# Pocket Math

A small, friendly Java Swing calculator for primary-school arithmetic practice.

## Run it

From the project folder, compile and start the program with Java 8 or later:

```powershell
javac -encoding UTF-8 -d out src\schoolcalculator\*.java
java -cp out schoolcalculator.CalculatorApp
```

Run the automated validation checks with:

```powershell
java -cp out schoolcalculator.CalculatorEngineTest
```
